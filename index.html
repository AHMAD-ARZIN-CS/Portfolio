Chalkbyte

A workspace that runs your code and shows you what it is doing.

Executes C, C++, Python, JavaScript, Java and Bash inside an isolated Docker container, with live input, interrupt, and errors marked on the offending line. The visualizer traces execution step by step and draws what is actually happening in memory: stack frames, recursion depth, vectors with index markers, pointers and linked structures. Built on gdb for compiled languages and sys.settrace for Python. The same repository holds a 3D renderer written from scratch in Python with no libraries.

A tracer that lies is worse than no tracer. I check the drawn memory state against the debugger's own output on real programs, and the renderer prints its numbers at every stage of the pipeline so a single point can be followed from model space to pixel by hand.

Segmented Security Homelab

Three network zones, built to be attacked.

Arzin Systems sells vulnerability scanning, and the first run of that workflow could not be on a client's network. I specified and assembled a host from components against a fixed budget for local language model inference plus multi-VM virtualization, then provisioned three Linux VMs with separate accounts, resource limits and scheduled backups behind a three-zone firewall policy isolating the security zone from the office zone.

A firewall config is a claim until something tests it. I generated traffic across every zone boundary and confirmed what actually crossed, rather than reading the rules and assuming they held. That is the habit the whole business is built on.

East Bay Linked

A campus hub built privacy-first. Accessibility Award, MESAU Hacks 3.0.

Course help, housing, food assistance, campus resources and a textbook marketplace for students at Chabot, Diablo Valley and Cal State East Bay, every list filtered to the student's own campus. Privacy was a constraint rather than a feature: no phone numbers, emails or home addresses are displayed, housing shows the area only and never an exact address, and content can be marked helpful while people are never rated.

Accessibility was checked, not claimed: contrast ratios, tap target sizing and keyboard navigation across the build. That is what the award was given for.

  • Accessibility
  • Privacy by design
  • Web

AI Automation Pipeline

In production. Writeup in progress.

Outreach was consuming the hours I had for building the actual service. A multi-stage pipeline now produces 20 to 30 reviewed drafts per run: it scopes to businesses in a target area, extracts contacts, drafts messages, scores its own output against criteria, and routes results for human approval.

The system scores its own output before a person ever sees it, and no draft leaves the queue without human approval. The scoring pass matters more than the drafting, so I am hardening source-selection criteria and documenting failure modes.
